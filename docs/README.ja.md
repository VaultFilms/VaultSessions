<h1 align="center">VaultSessions</h1>

**普段使っているChatGPT・Gemini・Claudeを、それぞれのパーソナライズや好みを保ったまま会議に招き、人間とAIが一緒に考え、議論し、協働できるオープンソースの会議アプリです。**

## 特徴

- **いつものAIの個性を会議に。** 普段利用している公式Webチャットに接続し、既存の会話やパーソナライズを活用します。AI APIキーは不要です。
- **自然なグループ議論。** 接続したAIが順番に発言し、新しい視点を加えます。付け加えることがなければPASSします。接続中のAIが1つの場合は、1回の回答で終了します。
- **最初の回答者を自然に指定。** `@GPT`、`@ChatGPT`、`@Gemini`、`@Claude`、`To Gemini`などを使って指名できます。指定がなければランダムに選びます。
- **画像を共有。** 最大4枚の画像を添付または貼り付け、番号で指定しながら議論できます。
- **現在のページを共有。** 必要に応じて、ページから取得した本文を会議資料として渡せます。
- **要約とコピー。** 後から振り返ったり、次の会議へ引き継いだりするための要約を作成できます。
- **サイドバーと全画面表示。** 表示形式の切り替え、参加者欄の折りたたみ、ログの文字サイズ変更に対応しています。
- **英語・日本語に対応。** 基本言語は英語です。翻訳カタログを追加して対応言語を増やせます。ダークモードはブラウザ・システムの設定に従います。

VaultSessionsは、異なるAIの文脈や個性と、人間の視点を一つの議論に持ち込む会議インターフェースの概念実証です。OpenAI、Google、Anthropicとの提携関係はなく、各社からの承認・推奨を受けたものでもありません。

## インストール

```text
VaultSessions/
├── README.md
├── LICENSE
├── SECURITY.md
├── docs/
└── VaultSessions/       ← Chromeにはこのフォルダを読み込む
    ├── manifest.json
    ├── meeting.html
    ├── start.command
    ├── start.bat
    ├── serve.py
    ├── icons/
    ├── i18n/
    └── ...
```

1. このリポジトリをダウンロードまたはクローンし、継続して保存しておくフォルダに配置します。
2. Chromeで `chrome://extensions/` を開き、**デベロッパーモード**を有効にします。
3. **「パッケージ化されていない拡張機能を読み込む」**をクリックし、`manifest.json` が入っている内側の **`VaultSessions/`** フォルダを選択します。リポジトリのルートではありません。
4. 利用したいChatGPT・Gemini・Claudeの公式サイトを開き、ご自身でログインします。
5. 会議サイドバーを表示したいタブで、VaultSessionsの拡張アイコンをクリックします。

最新のChromeをご利用ください。マニフェスト上の最低バージョンはChrome 116ですが、ブラウザAPIや各社の画面との互換性は環境によって異なります。通常の会議にはビルド作業やサーバーの起動は必要ありません。

ファイルを更新した後は、拡張機能、各AIの公式タブ、会議画面を再読み込みしてください。

### サーバー不要の全画面表示

1. 拡張機能の**「詳細」**で、**「ファイルのURLへのアクセスを許可する」**を有効にします。
2. `VaultSessions/meeting.html` をChromeで開きます。
3. **「この会議ページを登録」**をクリックします。このローカルページの正確なURLが、拡張機能のローカルストレージに保存されます。
4. ヘッダーの操作でサイドバーと全画面を切り替えます。

フォルダを移動した場合は、移動先の `meeting.html` を開いて再登録してください。サイドバーから全画面への切り替えでは、現在のタブを再利用します。元のWebサイトにはブラウザの「戻る」で戻れます。ログは引き継がれますが、AIへの再接続が必要になる場合があります。

### 任意のlocalhostモード

一部のAIブラウザサイドバーは、`file://` ページを操作できません。そのような連携を利用したい場合は、Python 3をインストールし、任意のループバックサーバーを起動します。

| 環境    | 起動ファイル                                   | ターミナルで起動する場合（内側の `VaultSessions/` フォルダで実行） |
| ------- | ---------------------------------------------- | ------------------------------------------------------------------ |
| macOS   | `VaultSessions/start.command` をダブルクリック | `python3 serve.py`                                                 |
| Windows | `VaultSessions/start.bat` をダブルクリック     | `py -3 serve.py` または `python serve.py`                          |

macOSの起動ファイルに実行権限がない場合は、`chmod +x start.command` を実行するか、上記のターミナル用コマンドを使用してください。起動したターミナルは開いたままにします。Ctrl+Cでサーバーを停止できます。ポート8766が空いている必要があります。

ファイル版の会議画面で **「?」** をクリックし、ヘルプモーダル内のサーバー確認・起動ボタンを使用してください。サーバーの応答を確認し、現在のログを保存してから切り替えます。アドレスは `http://127.0.0.1:8766/meeting.html` です。

サーバーはループバック上でのみ、内側の `VaultSessions/` フォルダのファイルを配信します。このフォルダに秘密情報や個人的なファイルを保存しないでください。どちらのモードでも拡張機能を有効にしておく必要があります。

## 使い方

### 会議を始める

利用可能なAIタブには自動接続します。同じAIのタブが複数ある場合は、接続したい会話を選択してください。タブを閉じずにAIを切断することもできます。切断後は、その会議画面で再び接続するまで自動再接続を停止します。

議題を入力してEnterで送信します。Shift+Enterで改行できます。日本語などのIME変換中には送信しません。複数のAIが接続されている場合は、最初の回答者に続いて他の参加者が順番に発言します。メッセージ中のどこにでも宛先指定を書けます。大文字・小文字は区別せず、複数ある場合は最初に登場する明示的な指定を採用します。

初期設定の上限は、**発言3回・問い合わせ6回**です。PASSは問い合わせ回数に含み、発言回数には含みません。接続中の全AIが連続してPASSした場合も議論を終了します。**「議論停止」**で次の発言への進行を止められます。ただし、入力が再び有効になるまでに、処理中の回答の回収を終える必要がある場合があります。

送信・回答回収中はAIタブが前面に表示されます。処理中の会話を直接編集したり、別の会話へ移動したりしないでください。フォーカス移動後の誤入力を防ぐため、入力保護が働きます。Role指示は通常のチャットメッセージであり、system roleではありません。個性の維持や指示への従順さを保証するものではありません。

### 画像と要約

PNG・JPEG・WebPの画像を最大4枚添付できます。容量は**1枚5MB・合計10MBまで**です。入力欄に画像を貼り付けるか、添付ボタンを使用してください。貼り付けデータに画像が含まれる場合は、テキストより画像の処理を優先します。送信前にプレビューを確認し、不要な画像は削除できます。

VaultSessionsは、ブラウザ内で画像を公式AIタブに渡します。プロジェクト独自の中継サーバーは使用しません。その後、送信時に公式サイトが各社のサーバーへ画像をアップロードします。画像の番号は、人間が新しく画像を添付して発言するたびに振り直されます。

**「議論を要約」**は、利用可能な接続中のAIをランダムに1つ選びます。新たな議論の往復は始めず、通常の300文字推奨制限も適用しません。成功すると、表示中のログとアプリ内の通常の会話履歴を要約に置き換えます。残しておきたい場合はコピーしてください。失敗時は元のログを維持します。要約は、その後にアプリが生成する議論用の履歴や、次回の要約の入力には含まれません。すでに送信したメッセージは、各社の会話に残ります。

### 表示と一時保存

ヘッダーのメニューで参加者・設定欄を隠せます。**「A−」「A＋」「標準に戻す」**で、要約を含むログ本文の文字サイズを75〜175％の範囲で調整できます。文字サイズの設定は表示形式間で共有され、ブラウザを再起動しても維持されます。

一時スナップショットには `chrome.storage.session` を使用し、1回の保存につき最大500件の表示ログと500件の通常履歴を保持します。開いている画面には、それより多く表示される場合があります。長期保存用のアーカイブではありません。言語・文字サイズ・ページ共有設定・登録したファイルURLには、ブラウザのローカルストレージを使用します。送信前に選択した画像は、表示切り替え時に保持されません。

### プライバシー・権限・互換性

**このアプリは、オフラインやループバック内だけで完結するものではありません。** 拡張機能内の連携や画像の受け渡しはブラウザ内で行いますが、公式AIサイトは、発言・画像・共有ページの本文を各社のサービスへ送信します。VaultSessions自身はAI APIのエンドポイントを直接利用せず、プロジェクト独自の中継サーバーも必要としません。

ソースコードの静的確認では、明示的な `fetch` は、任意のlocalhostモードで `http://127.0.0.1:8766/meeting.html` を確認する1か所でした。独立した解析クライアント、外部スクリプト・CDNのローダー、外部AI APIの直接呼び出しは確認されていません。これはソースコード上の確認であり、**通信を記録した実測監査ではなく、外部通信がないという主張でもありません。**

ページ共有には、ログイン済みページに表示される非公開情報が含まれる可能性があります。共有したくないページでは無効にしてください。URLのクエリ文字列を除去しても、ページ本文の個人情報は除去されません。権限・データの流れ・セキュリティ報告方法については、[SECURITY.md](SECURITY.md)を参照してください。

**VaultSessionsは、ログイン済みの各社公式AIサイトを自動操作します。各社の利用規約やアカウントに関する規則に抵触する可能性があります。適用される規約を確認し、自己責任で利用してください。各社の画面・ブラウザAPI・機能・規約が変更されると、動作しなくなったり、利用を中止する必要が生じたりする場合があります。** CAPTCHAや利用回数制限は回避しません。オープンソースであることは、独立した監査が実施済みであることや、安全性を保証するものではありません。
